# Inbox

Drop raw material here: notes, photos of panels, screenshots, exported voice transcripts,
old Word sections. Name files by component id when you know it, e.g.
`starting-panel_photo-knob.jpg`, `fuel-panel_notes.md`.

An AI session (see `CLAUDE.md`) turns these into component chunks and opens a pull request.
Processed files are moved to `inbox/done/`.
